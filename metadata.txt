about=OSM Data Toolkit downloads OpenStreetMap data from the Overpass API for an area you draw on the map or define using coordinates, turning it into ready-to-use QGIS layers without leaving QGIS.

    Choose from categories such as points of interest, bus, rail and ferry stops, roads, railways, waterways, buildings, administrative boundaries, landuse and open public spaces. Each category is organised into separate point, line and polygon layers.

    Features:
    - Draw a rectangle on the canvas or enter coordinates for the area of interest
    - Select the OSM feature categories to download
    - Export to GeoPackage (all layers in one file) or Shapefile
    - Optional local cache for faster repeat downloads
    - Optional automatic loading of results into the QGIS project
    - Support for large areas, with progress tracking and a processing log
    - Multilingual interface with a language selector and 33 supported languages
    - Dedicated translation modules for each supported language
    - Switch interface languages directly within the plugin

    Notes: An internet connection is required. Very large areas can take a long time and may be limited by public Overpass servers. GeoPackage is recommended for large datasets because Shapefiles have attribute and field-name limitations.

    Data (c) OpenStreetMap contributors, available under the Open Database Licence (ODbL). This plugin is not endorsed by or affiliated with the OpenStreetMap Foundation.
