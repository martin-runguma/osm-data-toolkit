01 · INPUT AREA

Area of interest selection

The plugin supports four AOI methods. Each method supplies a bounding box for the download request.

Current map extent

Use the visible extent of the QGIS map canvas. Pan and zoom to the required area, then update the current map extent in the plugin dialog.

Draw rectangle

Activate Draw AOI and click-drag a rectangle on the QGIS map canvas.

Selected features

Make a vector layer active, select one or more features, and use their combined bounding box.

Active layer extent

Use the extent of the currently active layer.

The dialog displays coordinates in south, west, north, east order for review before downloading.

03 · PROCESSING

Download processing

After the user selects an AOI and one or more categories, the plugin requests matching data from the Overpass API. Downloads run in a background thread and the interface provides progress and a Processing Log.

Returned OSM elements are classified into the selected feature categories and organised into geometry-based layers. Multipolygon relations are assembled into polygons, including holes, where the data allows.

Each Overpass request allows up to 300 seconds. Public server availability and response size can affect the time and success of a request.

04 · EXPORT

GeoPackage and Shapefile output

GPKG

GeoPackage

  • All layers are stored inside one .gpkg file.
  • All OSM tag columns are retained.
  • Text field length is not limited to 254 characters by the Shapefile constraint.
  • Recommended when a layer has many different OSM tags or every tag must be kept.
SHP

Shapefile

  • Each output layer is written as its own Shapefile file set.
  • Text fields are limited to 254 characters.
  • Column storage is constrained by an approximately 65 KB record limit.
  • If the layer still exceeds the limit, the plugin omits the least-frequent tag columns and reports them in the Processing Log.

Shapefile output also has two documented behaviours: administrative boundaries are written as separate files for each admin_level present, alongside the combined file; bus-station polygons are converted to centroids and merged into the bus-stop points layer.

05 · FILES

Output naming conventions

The naming dialog asks for a city, country, region and area-of-interest name. The values are joined with underscores to create the output base name. Characters that are not allowed in file names are cleaned up automatically.

EXAMPLE BASE NAMENairobi_Kenya_NairobiCounty_CBD
GeoPackageNairobi_Kenya_NairobiCounty_CBD.gpkg
Shapefile layerNairobi_Kenya_NairobiCounty_CBD_roads_line.shp

07 · ATTRIBUTES

OSM metadata and tag preservation

Every output layer includes the following OSM metadata fields, followed by one column for each OSM tag found in the data:

osm_idosm_typeosm_versionosm_timestamposm_changesetosm_uidosm_user

OSM tag names are case-sensitive, while GeoPackage and Shapefile field names are not. If two tags differ only by case (for example, fixme and FIXME), the later one is stored with a numeric suffix, such as FIXME_2, so the values can remain distinct.

GeoPackage preserves all OSM tags. Shapefile's record-size and field-length constraints can limit which tag fields are written; any omitted rare tag columns are reported in the Processing Log.

08 · ADMINISTRATIVE DATA

Administrative boundaries

Select Administrative boundaries to download features tagged boundary=administrative. The plugin offers an administrative-level filter: choose specific admin_level values from 0 to 15 or leave the selection to include all levels.

For Shapefile output, the plugin writes additional separate boundary files for each admin_level present (for example, suffixes such as _Lvl4 and _Lvl6) alongside the combined administrative-boundary output.

09 · SERVICE BEHAVIOUR

Overpass API endpoints and fallback

The documented endpoint order is:

  1. overpass-api.de — primary endpoint
  2. lz4.overpass-api.de — fallback endpoint
  3. overpass.kumi.systems — additional fallback endpoint

If an endpoint fails after retrying, the plugin tries the next server. Each request has a timeout of up to 300 seconds. These are shared public services; very large or repeated requests can be slow or rejected.

For service usage guidance, see the Overpass API public instance guidance ↗.

10 · LOCAL FILES

Caching and temporary files

When the local cache option is enabled, repeated identical queries can reuse earlier results instead of sending the same request to Overpass again.

During export, results are first written to a temporary GeoPackage named with the .osm_toolkit_temp_*.gpkg pattern in the output folder. The file is converted to the chosen format and then removed. The plugin documentation states that only files matching this temporary pattern are deleted.

11 · SUPPORT

Troubleshooting

What you seeWhat to do
Download fails or times outTry a smaller AOI, select fewer categories, or retry later when the public Overpass servers are less busy.
Unclassified OSM elements are reportedThis is informational. These are mostly untagged vertices already used in line and polygon geometries.
Some tag columns are missing in ShapefileShapefile has a record-size limit. Check the Processing Log for omitted columns; use GeoPackage to keep every OSM tag.
Text is cut off at 254 charactersThis is a Shapefile text-field limit. Use GeoPackage for longer text values.
Columns appear as fixme and FIXME_2OSM tags that differ only by letter case are kept separately; the later field receives a numeric suffix.
Old plugin behaviour remains after updatingRestart QGIS completely so the updated code is loaded.
When opening an issue

Include your QGIS version and operating system, the output format, the approximate AOI size and the full error message from the Processing Log. Open a GitHub issue ↗.
