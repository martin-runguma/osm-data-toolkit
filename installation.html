CHOOSE AN INSTALLATION METHOD

Three ways to install

For most users, the Plugin Manager is the simplest route.

METHOD 01Recommended

QGIS Plugin Manager

Install directly from the official QGIS plugin repository.

  1. Open QGIS.
  2. Go to Plugins → Manage and Install Plugins….
  3. Search for OSM Data Toolkit.
  4. Select the plugin and click Install Plugin.
View the official plugin page ↗
METHOD 02

Install from ZIP

Use a downloaded plugin package when you have the ZIP file locally.

  1. Download the latest plugin ZIP from the QGIS Plugins Repository.
  2. In QGIS, open Plugins → Manage and Install Plugins….
  3. Choose Install from ZIP in the plugin manager.
  4. Browse to the ZIP package and click Install Plugin.
Download plugin ZIP ↗
METHOD 03

Install from source

Use this method when working with the plugin source or managing a manual installation.

  1. Open the GitHub repository.
  2. Obtain the plugin package and locate the OSM_Data_Toolkit folder.
  3. Copy that folder into your QGIS Python plugins directory.
  4. Restart QGIS, then enable the plugin in the Plugin Manager.
i

After installation, confirm that OSM Data Toolkit is enabled in the Installed tab of the Plugin Manager. Open it from the QGIS Plugins menu or its toolbar icon.

MANUAL INSTALLATION

Where QGIS stores plugins

The following default-profile locations are documented in the project README. If you use a different QGIS profile, use that profile's corresponding plugin directory.

Operating systemDefault plugin directory
Windows%APPDATA%\QGIS\QGIS3\profiles\default\python\plugins
Linux~/.local/share/QGIS/QGIS3/profiles/default/python/plugins
macOS~/Library/Application Support/QGIS/QGIS3/profiles/default/python/plugins
i

These are the profile paths listed in the repository documentation. The active profile and QGIS installation can affect the exact location on an individual computer.

FIRST DOWNLOAD

Quick start: your first OSM extract

Once the plugin is installed and enabled, follow these steps from the main plugin dialog.

1

Define your area

Use the current map extent, draw an AOI rectangle, use selected features, or use the active layer extent.

2

Choose categories

Select the OpenStreetMap feature groups you need. For administrative boundaries, choose levels or leave the filter at all levels.

3

Set output options

Choose GeoPackage or Shapefile, set the output folder, and optionally enable automatic layer loading and local cache reuse.

4

Name and download

Click Download OSM Data, enter the city, country, region and area name, then select Continue to Download.

5

Review the Processing Log

Follow the progress log. When the download finishes, the output files are available in the chosen directory and may be added to the QGIS project automatically.

EXAMPLE OUTPUT NAMENairobi_Kenya_NairobiCounty_CBD

The city, country, region and AOI labels are combined with underscores. Characters not allowed in file names are cleaned up automatically.

A PRACTICAL TIP

Start with a small AOI and only the categories you need. Buildings and roads can produce especially large downloads.
