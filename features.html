OSM Data Toolkit brings together flexible area selection, focused OpenStreetMap categories and practical export controls in a single QGIS workflow.

01 · AREA OF INTEREST

Four ways to define your AOI

Use the current project view, draw a boundary, or derive the bounding box from an existing layer or selection.

01
▣

Current map extent

Pan and zoom the QGIS canvas to your study area, then update the AOI using the current map extent.

02
▱

Draw rectangle

Activate the draw-AOI tool and click-drag a rectangle directly on the map canvas.

03
⌑

Selected features

Make a vector layer active, select one or more features, and use the bounding box of the selection.

04
▤

Active layer extent

Choose a layer in the project and use its extent as the download area.

i

The dialog displays the AOI coordinates in south, west, north, east order so you can review the bounding box before downloading.

02 · OSM FEATURE CATEGORIES

Eleven ways to focus your download

Each selected category is classified into separate point, line and/or polygon layers according to the feature geometry.

POI

Points of interest

Shops, offices, industrial features, selected amenities, leisure and building values.

OSM tags: shop, office, industrial, selected amenity, leisure, buildingPoints
BUS

Bus stops

Bus stop nodes, bus stations and public-transport platforms or stations.

highway=bus_stop, amenity=bus_station, public_transport=platform/stationPoints · Polygons
RAIL

Rail stops

Stations, halts, platforms, tram stops and subway entrances.

railway=station, halt, platform, tram_stop, subway_entrancePoints
FERRY

Ferry stops

Ferry terminal locations.

amenity=ferry_terminalPoints
RD

Roads

Road and path features selected by the highway key.

highway=*Lines
RL

Railways

Railway features selected by the railway key.

railway=*Lines
WTR

Waterways

Waterway features and mapped water bodies, including wetlands, bays and reservoirs.

waterway=*, natural=water/wetland/bay, landuse=reservoirLines · Polygons
BLD

Buildings

Building footprints and areas marked with slum or informal tags.

building=*, slum=yes, informal=yesPolygons
ADM

Administrative boundaries

Administrative boundary polygons, with an optional administrative-level filter.

boundary=administrativePolygons
LU

Landuse

Landuse polygons, including areas marked with slum or informal tags.

landuse=*, slum=yes, informal=yesPolygons
PARK

Open public spaces

Parks, playgrounds, recreation grounds, forests, cemeteries, beaches and riverbanks.

leisure, landuse=forest/cemetery, natural=beach, waterway=riverbankPoints · Polygons
One OSM element can appear in more than one category.

For example, a park can match both Landuse and Open public spaces, so it may appear in each corresponding output layer.

03 · DOWNLOAD & PROCESSING

Practical controls behind the download

These capabilities help manage requests, organise returned features and make repeated work more convenient.

A

Administrative-level filtering

When Administrative boundaries is selected, choose specific admin_level values from 0 to 15 or request all levels.

B

Overpass server fallback

Requests try overpass-api.de first, then the documented fallback servers if a server fails after retrying.

C

Local query cache

When enabled, a repeated identical query can reuse a cached response instead of contacting Overpass again.

D

Background processing

Downloads run in a background thread, with progress and a live Processing Log in the plugin interface.

E

Two export formats

Save results as a single GeoPackage or as individual Shapefile layer sets.

F

Automatic layer loading

Enable the option to add completed output layers to the current QGIS project automatically.
