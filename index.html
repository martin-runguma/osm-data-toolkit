OUTPUT THAT FITS YOUR PROJECT

Two familiar formats.
Organised GIS layers.

Choose GeoPackage to keep all returned OSM tags together in one file, or Shapefile when your workflow needs the format. The plugin organises results by category and geometry.

GPKGGeoPackageOne file containing all output layers. Recommended when retaining every tag matters.
SHPShapefileA separate file set for each layer, with format-specific attribute limits.
